## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Stat Calculator** | Plan stat allocation and see weapon and spell scaling at target level |
| **Weapon Finder** | Find weapons that scale best with your planned stat distribution |
| **Build Templates** | Browse community build templates filtered by playstyle or weapon |
| **Level Planner** | Calculate levels needed to hit required stats for your target build |
